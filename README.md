## 📄 VizzioDocs

**VizzioDocs** adalah aplikasi **web pengolah dokumen berbasis Laravel** yang menyediakan berbagai alat untuk membantu pengguna mengelola file **PDF dan dokumen digital** secara **cepat, praktis, dan mudah digunakan** langsung melalui browser.

Website ini dirancang sebagai **platform all-in-one untuk kebutuhan dokumen**, sehingga pengguna tidak perlu menginstal banyak aplikasi terpisah untuk melakukan konversi, penggabungan, atau pengeditan file PDF.

### ✨ Fitur Utama

* 📑 **Merge PDF** – Menggabungkan beberapa file PDF menjadi satu.
* ✂️ **Split PDF** – Memisahkan halaman PDF sesuai kebutuhan.
* 🗜️ **Compress PDF** – Mengurangi ukuran file PDF.
* 🔄 **Convert PDF** – Konversi PDF ke berbagai format dokumen dan gambar.
* 🖼️ **Image to PDF** – Mengubah gambar menjadi file PDF.
* 📄 **PDF to Image** – Mengekspor halaman PDF menjadi gambar.
* 🔒 **Protect PDF** – Menambahkan password pada file PDF.
* 🔓 **Unlock PDF** – Membuka proteksi PDF yang memiliki izin akses.
* 📱 **Responsive Design** – Dapat digunakan di desktop maupun perangkat mobile.

### 🛠️ Teknologi yang Digunakan

* **Laravel**
* **PHP**
* **Blade Template**
* **Tailwind CSS**
* **JavaScript**
* **Vite**

### 🎯 Tujuan Proyek

VizzioDocs dibuat untuk menyediakan solusi **pengelolaan dokumen digital yang sederhana namun lengkap**, dengan fokus pada:

* Kemudahan penggunaan.
* Proses yang cepat dan efisien.
* Tampilan modern dan responsif.
* Akses langsung melalui browser tanpa instalasi tambahan.
